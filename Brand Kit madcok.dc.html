05 — Usage Guidelines
✓ Do
Use on dark backgrounds (#05080f or close)
Maintain clear space equal to the horn height around the mark
Use minimum 44px display size for the mark
Use Space Grotesk for all brand copy
Use #38bdf8 as the sole accent color
✗ Don't
Rotate or distort the mark
Change the accent color (#38bdf8 only)
Place the logo on busy or low-contrast backgrounds
Use the mark smaller than 24px
Add drop shadows, gradients, or effects to the wordmark
